# 研究室サイト 構成デモ

「CMSも保守契約もなしで、研究室サイトは学生とスタッフだけで運用できる」ことを示すための実証用サイト。

**中身はすべて架空のサンプル**（サンプル研究室／山田太郎ほか）で、実在の研究室の情報は一切入っていない。
図版も `make_placeholders.py` が図形として描いたもので、写真は1枚も使っていない。

## 何が見られるか

| URL | 内容 |
|---|---|
| `/` | **現行デザインの再現**。全7ページ。編集の練習はここで行う |
| `/styles/` | デザイン候補の一覧 |
| `/styles/c/` | 案C 青・情報密度 |
| `/styles/a/` | 案A 白・余白・端正 |
| `/styles/b/` | 案B ダーク・写真主導 |

トップに出るのが**現行デザインの再現**。いまのサイトと同じ左メニュー・右バナー列・訪問者カウンタを、
CMSを使わない素のHTMLとCSSだけで作っている。**見た目を1ミリも変えなくても、CMSと保守契約は外せる**という証明。

各ページ上部の黒い帯からデザイン候補に切り替えられる（デモ用。本番では消す）。

## 構成

```
data/       中身のデータ（CSV）。ニュースや業績を足すときはここに1行足す
  news.csv          日付,分類,本文
  members.csv       氏名,役職,専門分野,メール,写真
  publications.csv  年,種別,タイトル,掲載先,OA
pages/      本文だけを書いたHTMLの断片（研究内容・設備・アクセス）
assets/     現行デザインのスタイルシートと画像
themes/     デザイン候補のスタイルシート
   ↓ python build.py
docs/       出来上がったサイト。このフォルダが公開される
```

## 使い方

```bash
python build.py
```

これだけで `docs/` に全ページが生成される（デザイン候補ページも一緒に作られる）。
`python make_placeholders.py` は図版を作り直したいときだけ。

## 更新のしかた

**ニュースを1件足す** … `data/news.csv` の2行目に1行足して `python build.py`。
トップページと一覧ページの両方に自動で反映される。

**論文を1本足す** … `data/publications.csv` に1行足すだけ。同じく両方に反映される。

**メンバーを増やす** … `data/members.csv` に1行足す。

**文章を直す** … `pages/` の中のHTMLを開いて書き換える。使っているタグは `<p>` `<h2>` と表くらい。

**色を変える** … `assets/genkou.css` のいちばん上、`:root{ }` の中の色だけ直せばサイト全体が変わる。

**どこを直せばどこが変わるか** … 生成されたHTMLに `<!-- [news] -->` のようなコメントが入っている。
CSSも `.gnews` のように同じ名前でまとまっている。

## 公開のしかた

このリポジトリは GitHub Pages で公開している。
Settings → Pages で Source =「Deploy from a branch」、Branch = `main` / `/docs`。

```bash
python build.py
git add -A
git commit -m "更新内容を一言で"
git push
```

push から1〜2分でサイトに反映される。**これがそのまま本番の運用手順になる。**

## 注意

- 全ページに `<meta name="robots" content="noindex,nofollow">` を入れてある。
  検索結果に出て本物のサイトと混ざらないようにするため。**この行は消さないこと。**
- 本番では図版を実際の写真に差し替える。`assets/img/` を置き換えるだけでよい。
